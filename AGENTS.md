# LabSync

Web-based lab attendance + asset management system for university computer labs. UI text is Indonesian (Bahasa Indonesia).

## Repo layout

```
Frontend/          React 19 + Vite 8 + Tailwind v4 (working UI prototype)
prd_app_proyek3.md Full PRD — backend (Go+Fiber), DB (Supabase PostgreSQL), face verification (Python+DeepFace microservice)
diagram-proyek3-plantuml.md  PlantUML diagrams (ERD, sequence, activity, etc.)
```

Backend (Go+Fiber), face verification microservice (Python+FastAPI), database (Supabase), and API auth are **not yet built** — only specified in PRD.
